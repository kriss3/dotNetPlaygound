# Project Description
This project is a console application that demonstrates how to use an in-memory cache in C#.

It is based on Medhat Elmasry article:  
[In-Memory Caching in ASP.NET Core](https://www.c-sharpcorner.com/article/in-memory-caching-in-asp-net-core/).

I'm using private Postman collection based on Northwind database to demonstrate how to use an in-memory cache in C#.
